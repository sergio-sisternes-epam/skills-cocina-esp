# Skills de cocina en español

Colección abierta de skills para ayudar a cocinar en español: técnicas,
recetas, planificación de menús, sustituciones e interpretación de
ingredientes.

## Estructura

- `skills/`: skills publicables, una carpeta por skill.
- `skills/README.md`: convenciones para crear nuevas skills.
- `CONTRIBUTING.md`: guía breve para colaborar.

## Primeros pasos

1. Crea una carpeta dentro de `skills/` con un nombre corto en kebab-case.
2. Añade un `SKILL.md` con el objetivo, las instrucciones y ejemplos.
3. Comprueba que las instrucciones sean claras, seguras y útiles para
   personas con distintos niveles de experiencia.
4. Abre un pull request describiendo el caso de uso y los ejemplos incluidos.

## Principios

- Usar español claro y natural.
- Indicar cantidades, tiempos y temperaturas con unidades explícitas.
- Señalar alérgenos y advertencias de seguridad alimentaria cuando aplique.
- No sustituir el criterio de profesionales sanitarios o de seguridad
  alimentaria.
