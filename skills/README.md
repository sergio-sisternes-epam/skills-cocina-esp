# Skills

Esta carpeta contiene las skills de cocina del proyecto.

## Plantilla

```text
skills/
└── nombre-de-la-skill/
    └── SKILL.md
```

Un `SKILL.md` debería incluir:

1. Un título y una descripción del objetivo.
2. Cuándo debe utilizarse.
3. Instrucciones paso a paso.
4. Uno o dos ejemplos de entrada y salida.
5. Advertencias de seguridad o alérgenos, si aplica.

Usa nombres en kebab-case y una skill por directorio.
