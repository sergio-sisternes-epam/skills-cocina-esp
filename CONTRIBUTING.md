# Contribuir

Gracias por contribuir a `skills-cocina-esp`.

## Proceso

1. Crea una rama descriptiva a partir de `main`.
2. Añade o modifica una skill manteniendo la estructura existente.
3. Revisa ortografía, unidades, tiempos, temperaturas y advertencias.
4. Abre un pull request con una descripción breve del cambio y ejemplos de
   uso.

## Formato de una skill

Cada skill debe vivir en `skills/<nombre>/SKILL.md`. Mantén las instrucciones
centradas en una tarea concreta y evita duplicar contenido que pueda ser
reutilizable en otra skill.

## Seguridad

Las instrucciones no deben presentar como seguras prácticas que puedan causar
intoxicaciones, quemaduras u otras lesiones. Incluye advertencias específicas
cuando sean necesarias.
